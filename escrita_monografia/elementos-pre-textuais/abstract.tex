This work presents the development of a mobile robotic platform based on the adaptation of a commercial floor vacuum cleaner robot to function as a line-following robot using Proportional-Integral-Derivative (PID) control. The aim is to create an open and documented robotic platform that can be replicated and adapted by other researchers, students, and teachers for various educational and practical applications. The platform is based on a Raspberry Pi with Linux Ubuntu and Robot Operating System (ROS2), responsible for processing and control, and an ESP32 microcontroller dedicated to reading line sensors. The vacuum cleaner robot was modified to allow integration with electronic components and software, becoming a tool for application in robotics projects in a wide range of sectors. The proposal includes the implementation of communication between devices, providing a practical and accessible environment for experimentation and learning. Finally, documentation for the operation and modification of the platform will be prepared.
