\chapter{Objetivos}
\section{OBJETIVO GERAL}

Desenvolver uma plataforma robótica móvel baseada na adaptação de um robô aspirador comercial para atuar como robô seguidor de linha com controle PID, com o propósito de criar uma ferramenta aberta, documentada e replicável para experimentação e pesquisa em robótica aplicada.

\section{OBJETIVOS ESPECÍFICOS}
\begin{itemize}
    \item Adaptar o robô aspirador para integração de sensores de linha e controle PID;
    \item Implementar a comunicação entre Raspberry Pi, ESP32 e ROS2 para controle e aquisição de dados;
    \item Desenvolver o software necessário para o funcionamento do robô seguidor de linha utilizando ROS2;
    \item Prover documentação detalhada sobre o hardware, software e procedimentos para operação e modificações futuras;
    \item Facilitar o uso da plataforma em ambientes experimentais e desenvolvimento de projetos práticos em robótica.
\end{itemize}
